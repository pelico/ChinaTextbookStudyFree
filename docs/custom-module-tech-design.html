1. 架构总览

用户浏览器 │ ├──→ nginx :80 (静态页面) ──→ /usr/share/nginx/html/* │ │ │ ├── /api/retry?resource=audio → nc 服务 :18080（现有） │ └── /api/custom/* → Python SQLite 服务 :18081（新增） │ │ │ ├── SQLite: /data/custom.db（Docker volume 持久化） │ ├── 图片: /data/images/（Docker volume） │ └── AI 调用 ──→ Gemini / OpenAI 兼容 API（HTTPS） │ └──→ localStorage（积分/经验/成就，现有系统不变）

核心设计原则

  • 大纲固定，题目可刷新：知识点框架一次生成后稳定存储在 SQLite；每次练习时 AI 生成新题目，旧版本保留可回顾
  • 积分系统零改动：自定义 lesson 用 custom-{bookId}-u{n}-kp{m} 格式的 ID，直接复用现有 Zustand store
  • AI 调用服务端：Python 后端调用 AI API，API Key 存环境变量不暴露给浏览器
  • 零额外依赖：Python 标准库 http.server + sqlite3 + urllib.request，不装 pip 包

2. SQLite 数据库设计

数据库文件路径：/data/custom.db，映射到 Docker volume cnstudy-custom-data。 图片文件存 /data/images/，同样映射到 volume。

表结构

books — 自定义书本

CREATE TABLE books (
  id          TEXT PRIMARY KEY,          -- "custom-gz-math-g3up"（自定义命名）
  title       TEXT NOT NULL,              -- "广州版小学数学三年级上册"
  subject     TEXT NOT NULL,              -- "math" | "chinese" | "english" | "science"
  grade       INTEGER NOT NULL,           -- 1-6
  semester    TEXT NOT NULL,              -- "up" | "down"
  source_type TEXT DEFAULT 'photo',       -- "photo" | "manual" | "import"
  cover_image TEXT,                       -- 封面图路径（可选）
  created_at  TEXT NOT NULL,              -- ISO 时间戳
  updated_at  TEXT NOT NULL
);

units — 单元

CREATE TABLE units (
  id           TEXT PRIMARY KEY,          -- "{bookId}-u{n}"
  book_id      TEXT NOT NULL REFERENCES books(id) ON DELETE CASCADE,
  unit_number  INTEGER NOT NULL,
  title        TEXT NOT NULL,
  sort_order   INTEGER DEFAULT 0
);
CREATE INDEX idx_units_book ON units(book_id);

knowledge_points — 知识点（大纲框架，固定）

CREATE TABLE knowledge_points (
  id             TEXT PRIMARY KEY,        -- "{bookId}-u{n}-kp{m}"
  unit_id        TEXT NOT NULL REFERENCES units(id) ON DELETE CASCADE,
  name           TEXT NOT NULL,            -- "认识图形"
  description    TEXT,                      -- "能识别长方形、正方形..."
  difficulty     INTEGER DEFAULT 3,        -- 1-5
  question_types TEXT DEFAULT '[]',        -- '["true_false","choice","fill_blank_text"]'
  sort_order     INTEGER DEFAULT 0,
  source         TEXT DEFAULT 'ai',        -- "ai"（AI 从照片提取）| "manual"
  created_at     TEXT NOT NULL
);
CREATE INDEX idx_kp_unit ON knowledge_points(unit_id);

question_sets — 题目版本（可刷新）

CREATE TABLE question_sets (
  id           TEXT PRIMARY KEY,          -- UUID
  kp_id        TEXT NOT NULL REFERENCES knowledge_points(id) ON DELETE CASCADE,
  version      INTEGER NOT NULL,          -- 1, 2, 3...（同一知识点递增）
  questions    TEXT NOT NULL,              -- JSON 数组，Question[] 格式
  is_active    INTEGER DEFAULT 1,         -- 1=当前使用版本，0=历史版本
  ai_model     TEXT,                       -- "gemini-3.1-flash-lite"
  generated_at TEXT NOT NULL
);
CREATE INDEX idx_qs_kp ON question_sets(kp_id);
CREATE INDEX idx_qs_active ON question_sets(kp_id, is_active);

page_images — 教材拍照页

CREATE TABLE page_images (
  id          TEXT PRIMARY KEY,           -- UUID
  book_id     TEXT NOT NULL REFERENCES books(id) ON DELETE CASCADE,
  unit_id     TEXT,                        -- 关联到的单元（可为空，未分类时）
  filename    TEXT NOT NULL,               -- "page_001.jpg"
  ocr_text    TEXT,                        -- AI 识别出的文本内容
  page_number INTEGER,                    -- 页码
  created_at  TEXT NOT NULL
);
CREATE INDEX idx_img_book ON page_images(book_id);
设计要点：question_sets 的 version 字段实现题目刷新——每次"换一套题"生成新版本， 旧版本 is_active=0 保留，可做"错题回顾"或"历史版本对比"。 questions 字段存完整 JSON，与现有 Question 类型完全兼容。

3. REST API 接口规范

所有接口前缀 /api/custom，由 nginx 反代到 127.0.0.1:18081。

书本管理

方法路径说明

DELETE/api/custom/books/:id删除书本（级联删单元/知识点/题目）

知识点与题目

方法路径说明

4. Python 服务设计

架构

custom_server.py
├── HTTP Handler（ThreadingHTTPServer :18081）
│   ├── 路由分发（path 匹配 + JSON 解析）
│   ├── CORS 头处理
│   └── 错误处理
├── DB Layer（sqlite3 模块）
│   ├── init_db() — 建表
│   ├── CRUD 操作
│   └── 事务管理
├── AI Layer（urllib.request）
│   ├── ocr_images() — Vision API 识别教材图片
│   ├── generate_outline() — 从 OCR 结果生成大纲
│   └── generate_questions() — 根据知识点生成题目
└── Config（环境变量）
    ├── AI_API_BASE — AI 接口地址
    ├── AI_API_KEY — API Key
    └── AI_MODEL — 模型名

关键技术决策

  • ThreadingHTTPServer：AI 题目生成耗时 10-30s，多线程防止阻塞其他请求
  • urllib.request：标准库，无需 pip install，支持 HTTPS POST + 超时
  • multipart 解析：Alpine 无 Python requests 库，用标准库 cgi.FieldStorage 或手动解析 boundary
  • SQLite WAL 模式：PRAGMA journal_mode=WAL，读写不互斥
  • AI 超时 120s：与现有 worksheet.ts 一致

Python 服务核心流程

# 启动（在 docker-entrypoint.sh 中）
python3 /app/custom_server.py &

# custom_server.py 核心结构
import http.server, sqlite3, json, os, urllib.request, uuid, time

DB_PATH = os.environ.get("CUSTOM_DB_PATH", "/data/custom.db")
AI_BASE = os.environ.get("AI_API_BASE", "https://aiapi.fonken.net/v1")
AI_KEY  = os.environ.get("AI_API_KEY", "")
AI_MODEL = os.environ.get("AI_MODEL", "gemini-3.1-flash-lite")

def call_ai(messages, timeout=120):
    """调用 OpenAI 兼容 API，返回 content 字符串"""
    url = AI_BASE.rstrip("/") + "/chat/completions"
    body = json.dumps({
        "model": AI_MODEL,
        "messages": messages,
        "temperature": 0.7,
        "stream": False,
    }).encode()
    req = urllib.request.Request(url, data=body, headers={
        "Content-Type": "application/json",
        "Authorization": f"Bearer {AI_KEY}",
    })
    with urllib.request.urlopen(req, timeout=timeout) as resp:
        data = json.loads(resp.read())
        return data["choices"][0]["message"]["content"]

class CustomHandler(http.server.BaseHTTPRequestHandler):
    def do_POST(self):
        # 路由: /books, /lessons/:id/questions, /lessons/:id/refresh
        ...
    def do_GET(self):
        # 路由: /books, /books/:id, /books/:id/outline, ...
        ...

if __name__ == "__main__":
    init_db()
    server = http.server.ThreadingHTTPServer(
        ("127.0.0.1", 18081), CustomHandler
    )
    server.serve_forever()

创建书本流程（4 步）

步骤 1: 填写基本信息
  → 书名、学科、年级、学期

步骤 2: 拍照/上传
  → 调用 getUserMedia() 或 file input
  → 支持多张图片（教材目录页 + 内容页）
  → 前端预览，可删除/重排

步骤 3: AI 识图生成大纲
  → POST /api/custom/books (multipart, 含图片)
  → 后端调用 Gemini Vision API:
     1. 逐张识别图片内容，提取文本
     2. 汇总文本，调用 AI 生成结构化大纲 JSON
     3. 写入 SQLite books + units + knowledge_points + page_images
  → 前端展示大纲预览，用户可编辑/增删知识点

步骤 4: 确认创建
  → 大纲确认后，书本出现在首页列表
  → 点击任意知识点即可开始练习（首次自动生成题目）

9. 风险与边界

风险等级应对
AI 识图准确率不稳定（模糊/手写/排版不一）中用户可编辑大纲；prompt 强调"只提取能确认的内容"
题目生成超时（120s）低已有超时机制；Python 线程池不阻塞其他请求
SQLite 并发写冲突低WAL 模式 + 写操作加锁 + 重试
图片上传体积大中前端压缩到 1080p JPEG（max 500KB/张）；限制单次 20 张
API Key 暴露低Key 在服务端环境变量，不传给浏览器
自定义 lessonId 与现有冲突低统一前缀 custom-，与现有 g1up / chinese-g1up 无交集
无 TTS 朗读低MVP 跳过；后续可用浏览器 speechSynthesis 或 AI TTS API
边界约束：本方案不改动现有教材的学习路径、题目数据、音频文件。 自定义模块是独立路由 /custom/*，共用积分系统但数据完全隔离。 现有教材功能不受任何影响。
